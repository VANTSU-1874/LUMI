# 基于自建多模态检索增强的视觉传达设计教学智能体——LUMI 鹿鸣

LUMI 是一款面向设计教育的 AI 学习助手。它以学生正在学习的课程和正在推进的设计项目为上下文，帮助学生理解问题、组织证据、形成判断，并把讨论转化为可执行的下一步。

LUMI 不替代教师评价，也不把模型生成内容当作事实。课程知识、作品信息和历史记录只有在实际取得且适合当前任务时，才可作为回答依据。

## 服务的学习场景

- 理解设计概念、任务要求与创作目标。
- 梳理从选题、分析、方案形成到迭代完善的项目过程。
- 结合学生提供的截图、参数、节点或作品，逐步分析设计与制作问题。
- 在课程学习与具体项目之间建立联系，帮助学生说明自己的选择与取舍。

## 当前核心方向

项目围绕以下方向持续建设：

- **课程知识**：组织设计课程中的概念、方法、案例与软件工作流，为对话提供专业背景。
- **可追溯证据**：在资料确实可用时保留来源线索，区分可观察事实、学生意图与模型建议。
- **视觉案例与灵感**：探索以可核对的视觉案例支持观察、比较和灵感发现，不用生成内容替代真实作品证据。
- **项目化学习指导**：围绕学生当前项目推进追问、分析、反馈与下一步行动，而非只给出一次性答案。

## 能力边界

当前课程内容、专业路由和视觉分析能力仍在逐步建设，不代表已经覆盖全部设计课程或形成稳定的跨专业能力。

只有视觉模型实际可用且作品文件成功送达模型时，LUMI 才能基于作品画面进行分析。仓库中的路线图、实验、设计稿和候选方案均不等于已经完成或验收的产品能力；预置演示数据也不代表真实教学成效。

## 仓库范围与安全

本仓库保存 LUMI 的应用源码、必要配置、数据库迁移、测试、项目文档以及经过筛选的演示资源。

本仓库不包含：

- 课程原始素材或参赛提交资料；
- 学生个人数据、学习记录或作品文件；
- 环境变量文件；本地配置应由部署者依据运行手册单独创建；
- 生产密钥、访问令牌或其他私密凭证。
