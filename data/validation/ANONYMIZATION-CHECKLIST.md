# 历届作业匿名化检查清单

## 处理前

- [ ] 确认该作业的教学、验证和比赛内部使用范围；范围不清不入库。
- [ ] 为作业分配新的匿名编号；编号与真实身份的对应表不进入本仓库。
- [ ] 保留来源、课程和年份等必要教学元数据，但不保留可直接识别个人的信息。

## 文件与画面

- [ ] 删除姓名、学号、班级、联系方式、社交账号、签名、头像、人脸、可识别声音与定位。
- [ ] 清理 PDF、PPT、DOCX、图片、视频和截图的文件属性、修订记录、作者名、隐藏图层及备注。
- [ ] 裁切或遮挡软件界面中的本机用户名、文件路径、邮箱、账号、浏览器标签和聊天记录。
- [ ] 检查作品内文字、二维码、场景和照片是否仍可反向识别学生或无关第三方。

## 入库前复核

- [ ] 由第二人复核一次；无法确认时标记“待人工复核”，不进入验证集。
- [ ] 在 `ANNOTATION-TEMPLATE.md` 中逐项勾选匿名化确认。
- [ ] 仅保存教学所需的最小材料；原始可识别文件留在受控位置，不上传至本仓库。
- [ ] 需要删除时，能根据匿名编号定位并删除相应材料和衍生记录。

## 术语待议

- 无。
