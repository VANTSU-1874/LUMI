# 版式设计资料包（配置台演示初版）

> 用途：比赛切课时上传至配置台的**预置**材料包。内容从 `001-grid-and-hierarchy.md` 与 `002-type-hierarchy-and-whitespace.md` 提炼；来源性质为公开设计常识的课堂化转述，待用户提供教材后逐条核验和替换。

## 课程与使用边界

- 课程标签：版式设计
- 适合的问题：信息太多不知道从哪里排、标题与正文主次不清、页面拥挤、留白看起来像浪费。
- 回答方式：先追问读者、场景和第一信息；再提示栅格、分组、字体层级或留白中的一项关系；最后给一个局部对照动作。不给学生直接可提交的完整版式。
- 工艺与规范：具体成品尺寸、出血、字体授权、印刷或屏幕规范必须以项目任务书和教师材料核验。

## 知识卡 1：栅格与信息层级

栅格帮助信息建立对齐关系；信息层级帮助读者在有限时间里知道先看什么。先区分主要、次要和支撑信息，再用栏位、对齐线、间距和留白建立关系。导出实际尺寸预览或请同伴说出前三秒看见的内容，作为视觉动线的证据。

常见误区：所有内容同时放大/加粗；每块信息各自对齐；把栅格当成不可调整的框。建议只改一个变量并保留前后对照。

## 知识卡 2：字体层级与留白

标题、导语、正文和注释的角色可通过字重、字号、行距、位置和周边距离区分。留白用于分组、停顿和突出重点；相近信息保持较近距离，不同组之间留出更明显的间隔。

常见误区：不断增加字体数量；所有内容用同一种间距分隔；只在放大的编辑界面判断可读性。先列出每种字体承担的角色，再按实际输出尺寸检查阅读效果。

## 上传后的演示提问

“这是一张活动海报预置草图。读者只有三秒钟，你会先让他看到什么？请先问我目标受众和展示场景，再给一个只改一处的检查建议。”
