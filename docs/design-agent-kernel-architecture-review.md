# 触映 Design Agent Kernel 架构冲突审查

审查日期：2026-07-16
审查基线：`efe9ec7`
审查范围：Agent 编排、模型决策、路由、知识检索、工具注册、会话持久化、项目记忆和学生对话界面。

## 结论

当前实现是一个“课程包约束下的教育 Agent”，不是“覆盖艺术设计全专业的导师内核＋可选资源增强”。它能安全完成数字交互和书籍微闭环，但四个上游决定把自由设计对话压缩成了课程内问答：课程包先路由、课程知识作为唯一依据、工具由课程包预先白名单、无命中必须声明无依据。继续在学习证据或逻辑卡上加页面不能解决这个问题。海报、IP、TouchDesigner 和书籍只是审查样例，不是新内核的能力边界。

本轮必须把依赖方向改为：

```text
学生意图与连续会话
  -> DesignAgentKernel 正常回答并推进项目
  -> SpecialtyRouter 选择可选专业增强
  -> KnowledgeRetriever / ToolRegistry 按需增加深度
  -> ActionPolicy 只控制是否可自动执行
  -> ProjectBriefMemory 在后台更新项目理解
  -> 学习证据异步记录，供教师分析
```

课程知识、案例、工具和证据只能提高答案深度或可信度，不能决定是否允许回答。

## 关键冲突

| 冲突 | 当前实现 | 造成的产品后果 | 本轮处理 |
|---|---|---|---|
| 未识别问题默认进数字交互 | `resolveCoursePackId` 最终回落到 `digital-interaction` | 海报、IP、包装、UI 等问题被错误贴成数字交互 | 新增 `SpecialtyRouter`，默认 `GENERAL_DESIGN` |
| 课程知识是唯一知识来源 | 模型提示规定 `knowledge` 是唯一事实与步骤依据 | 模型自身的通用设计能力被禁用 | 通用设计知识可直接回答；课程事实仍须引用 |
| 无来源必须写“无依据” | Schema 与策略同时强制 `DISCLOSE_NO_EVIDENCE` | 普通设计建议被包装成能力缺失 | 改为来源分层：通用设计建议 / 课程知识 / 案例依据 / 工具结果 |
| 超范围等于不能制作 | `OUT_OF_SCOPE` 会清空行动并退回边界说明 | 非课程专业问题无法得到正常推进 | “超出当前专门资料”只降低专业增强，不阻断回答 |
| 工具由课程包先限制 | `listAllowedAgentTools(pack)` 与执行器按课程包双重筛选 | 工具选择服从课程包，而不是学生当前目标 | ToolRegistry 先按目标、权限和专业匹配；只读自动，写入确认 |
| 会话按课程包分片 | 最近对话和恢复查询都绑定课程包版本 | 学生从海报转到 TouchDesigner 时上下文断裂 | ConversationSession 跨专业恢复最近回合 |
| 没有项目简报记忆 | 只保存原始回合、项目阶段和证据摘要 | 模糊意图不能逐步沉淀为可编辑理解 | 新增 ProjectBriefMemory 与后台增量合并 |
| 回答结构围绕课程情境 | 六类 episode、课程决策码和课程行动白名单共同主导 | Agent 更像课程状态机，不像设计导师 | episode 只描述当前对话情境，不决定知识许可 |
| 学生入口强调证据与门禁 | 一级导航直接显示“学习证据”；工作台以阶段流程为中心 | 学生先看到课程管理负担，而不是创作推进 | 主界面突出对话、项目理解与下一步；证据降为“过程记录” |
| 模型接入与规则耦合 | OpenAI 兼容客户端存在，但规则、提示和模型调用写在同一决策文件 | 更换模型后难以单独验证身份与行为 | 新增 ModelProviderAdapter 与 AgentEvalHarness 身份测试 |

## 可保留资产

- OpenAI 兼容服务端模型调用、超时和响应大小限制。
- 版本化 AgentPolicy、有界模型—工具循环和执行轨迹。
- 只读工具自动调用、学生确认行动卡、正式评价禁止自动执行。
- 数字交互课程知识、TouchDesigner 案例网络、节点解析与排障状态。
- 书籍设计课程资料和 8 页微闭环。
- 教师追加式复核、真实/演示数据隔离、历史证据和发布 Harness。
- 完整问答与悬浮问答共享服务端会话的现有 UI 基础。

## 迁移边界

1. 不删除现有案例、节点、教师复核、证据或历史回合。
2. 旧回合缺少新来源分层和项目简报时必须可解析、可恢复。
3. 新的通用设计回答不能伪造课程来源；课程技术事实仍由资料或工具支撑。
4. TouchDesigner 等实时修改仍不开放自动执行，第一版桥接只读。
5. 现有阶段流程继续存在，但不再成为普通对话前置门禁。

## 第一稳定切片

- 通用设计问题不再默认进入数字交互，也不因课程无命中拒答。
- 模糊回答先得到暂时理解、2—3 个具体假设和一个关键追问。
- 项目简报在每轮后台更新并可在刷新后恢复。
- 数字交互与书籍问题自动获得课程知识、案例和只读工具增强。
- 学生回答明确显示“通用设计建议 / 课程知识 / 案例依据 / 工具读取结果”。
- 学习证据入口改为次级“过程记录”，既有教师与历史数据不删除。
- 固定行为测试覆盖海报、IP、模糊回答、TouchDesigner 深度、会话恢复和权限边界。
