# 触映导师知识语料来源清单

核对日期：2026-07-17。

任务 5.1 将知识条目从 8 条扩充到 34 条，覆盖通用设计、数字交互和书籍设计三个知识包。所有条目继续通过 `KnowledgeItemSchema` 登记来源、权威级别、核对日期、适用范围、事实与行动；检索结果只增强导师回答，不作为回答许可门禁。

## 来源分级

- `OFFICIAL`：赛事正式附件、Design Council、W3C、Adobe InDesign、Derivative TouchDesigner、DigiShow 官方页面。
- `COURSE_DESIGN`：触映内部 64 课时课程设计、通用设计项目简报规则、书籍设计微任务与证据设计。
- `TEACHER_EXPERIENCE`：保留给有可审计教师笔记、访谈或人工复核记录的经验；当前语料没有满足该证据条件的条目，因此不使用这一等级。
- `ANONYMIZED_CASE`：只保留去标识工程快照、案例版本与节点结构差异，不读取或暴露原始索引中的设备标识、本机路径、外部文件名和未核验链接。

## 覆盖范围

- 通用设计：Discover—Define—Develop—Deliver、模糊需求与项目简报、色彩非唯一线索、文字和控件对比度、文字间距适应、状态反馈、最小原型测试。
- 第一阶段：文化意图、六元交互逻辑与四阶段课程路径。
- 第二阶段：DigiShow 信号类型、映射、接口、灯光与 MIDI。
- 第三阶段：TouchDesigner 的 CHOP/TOP 数据流、声音分析、Filter、Math、Null、Feedback、GLSL 与版本案例对照。
- 第四阶段：OSC 发送接收、双工具协同、综合项目和迁移。
- 书籍设计：受众与阅读任务、信息层级、阅读证据、Kerning/Tracking、网格、链接素材、出血与印刷标记。

## 当前材料缺口

工作区没有独立的正式课程标准、教学大纲或 PPT/PPTX 教师课件，也没有已确认授权状态的优秀学生作品。内部课程规格只标为 `COURSE_DESIGN`，不得称为正式课程标准；官方网页摘要不得扩写为页面未支持的版本、菜单或设备结论。后续获得上述材料时，应先核对授权与个人信息，再增加新条目，不能为了满足数量而伪造来源。
