# 书籍设计课程基础说明

本说明把 `lib/course-packs/book-design.ts`、`Product-Spec.md` 与 `docs/pilot-protocol.md` 中已登记的书籍设计微任务整理为可引用的课程设计来源。它不是行业标准，也不替代印厂、软件厂商或字体授权方的当前要求。

## 微任务边界

- 任务是把校园社区活动介绍改编为面向新生的 8 页导览册。
- 学生先明确受众、阅读情境和阅读任务，再处理字体、色彩与装饰。
- 内容先分为必读、选读和延伸，再按读者任务组织封面、导读、正文与行动信息。
- 视觉系统用字号、网格、色彩和留白表达层级，但这些形式必须服务阅读路径。

## 证据与修订

- 保存信息层级排序、8 页缩略版面和读者任务测试。
- 版面比较时保持内容不变，一次只改变一个主要变量，例如栏数、字号级差或页序。
- 阅读验证记录读者是否找到活动与参与方式、在哪一页停顿或指向错误。
- 迁移到社区居民受众时，说明保留的核心内容与层级，以及因新情境改变的顺序、网格或字号。

这些记录用于支持导师给出课程内建议，不用于自动评分、判定过关或替学生提交作品。
