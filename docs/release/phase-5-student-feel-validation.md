## 真实提问

> 我是第一次做互动装置，想让声音带动画面变化。请用我能听懂的话告诉我第一步做什么。

真实 GPT-5.6 回答在约 22.3 秒内完成。回答体现了以下可用特征：

1. 先把目标缩小为“声音越大，画面里的圆越大”，没有让初学者一次搭完整作品。
2. 给出可执行链路：`Audio File In CHOP → Analyze CHOP（RMS Power）→ Math → 圆大小`。
3. 用“耳朵”和“测音量的人”解释 Audio File In 与 Analyze，同时保留必要专业名词。
4. 把第一步成功标准说成“Analyze 数值会跟着声音变化”，而不是笼统要求先做出漂亮画面。
5. 将 TouchDesigner CHOP 信号逻辑和课程链路列为可追溯依据，没有伪造外部搜索来源。

## 界面观察

- 桌面：标题、引用、编号步骤、项目符号、行内代码和依据区域层级清楚；长回答后输入框仍可见，可以自然追问。
- 390×844 移动视口：默认关闭侧栏，回答保持单列，输入区可见，没有被导航遮挡。
- 320×568 自动化视口：发送一个不可自然断行的长 URL 后，运行中消息气泡没有造成页面横向溢出。
- 模型 Markdown 由安全组件渲染；原始 HTML 不执行，模型生成的 Markdown 链接不直接变成可点击外链，只有经过结构校验的来源可点击。
