## L1 完整输出

声音控制图形大小，本质上是：先把麦克风声音变成一条不断变化的数值，再用这个数值控制图形的缩放。

先马上做第一步：

1. 在 TouchDesigner 的 Network Editor 空白处按 `Tab`。
2. 搜索并创建 `Audio Device In CHOP`。
3. 对着麦克风说话或拍一下手。

如果节点里的波形会跟着声音跳动，就说明声音已经成功进入系统。若一直是一条平线，在节点参数的 `Device` 中选择正在使用的麦克风。

接下来最小连接链是：

`Audio Device In CHOP → Analyze CHOP（Function 选 RMS）→ Math CHOP → 图形的 Scale 参数`

其中：

- `Analyze CHOP` 把声音波形转换成音量数值。
- `Math CHOP` 把数值调整到适合缩放的范围，例如 `0.5–2`。
- 将 `Math CHOP` 的通道拖到图形或 `Transform TOP` 的 `Scale` 参数上，选择 `Export CHOP`。

成功标准：你说话越大声，图形就越大；安静下来，图形就缩小。

## L4 完整输出

先做这一步：在 TouchDesigner 里按 `Tab`，进入 `CHOP`，创建一个 `Audio Device In`，选择你的麦克风或声卡输入。对着麦克风说话，先确认节点预览里的波形会跳动；这一步没信号，后面的图形就不会动。

接着搭一条最小可用链路：

```text
Audio Device In → Analyze → Math → Lag → Null
```

- `Analyze`：选择 `RMS Power`，把快速振荡的音频波形变成稳定的“响度”数值。
- `Math`：把实际响度范围映射到图形缩放范围。例如将安静到大声的实测值映射为 `0.8 → 2.0`，并开启限制，避免图形缩到负值或突然变得过大。
- `Lag`：增加约 `0.08–0.2 秒`的平滑，让图形有呼吸感，而不是跟着每个音频采样点发抖。
- `Null`：作为最终控制信号。把它的通道拖到 `Geometry COMP` 的缩放参数上，选择 `Export CHOP`；如果没有统一缩放参数，就分别导出到 `Scale X/Y/Z`。

这条链路的核心因果关系是：

```text
输入：声音振幅
处理：测量响度 → 映射范围 → 平滑变化
输出：图形大小
```

先预测一下效果：如果去掉 `Lag`，图形会更灵敏，但容易抖；如果平滑时间过长，动作会稳定，却会显得慢半拍。判断参数是否合适，可以看三点：安静时图形是否保持可见、大声时是否不过度膨胀、节奏停止后是否能自然回落。

如果你想让图形跟“低音鼓点”变化，而不是跟整体音量变化，就把链路改为：

```text
Audio Device In → Audio Spectrum → 选取低频段 → Analyze → Math → Lag
```

同一个经过归一化和平滑的声音信号，也可以迁移去控制线条粗细、亮度、粒子发射量或镜头位移；保留的是“声音特征驱动视觉参数”的因果链，改变的是表现媒介。
