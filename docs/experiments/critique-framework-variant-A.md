# Lumi 鹿鸣结构化会诊框架提案（Variant A）

> 状态：**待用户定稿**  
> 用途：为主线 Task 3 提供可配置的内容提案，不代表六维框架已经确定，不包含任何功能实现。  
> 适用面孔：Lumi 的**设计导师面孔**。软件操作或故障类问题应切换到**软件师傅面孔**，采用证据式排错，不套用本框架。

## 1. 提案摘要

Variant A 建议保留一套跨课程可比较的六维骨架，再由课程配置替换每一维的检查要点与示例语句：

1. 意图与信息
2. 受众与场景
3. 信息层级与视觉动线
4. 形式语言
5. 工艺与规范
6. 亮点与最近改进点

每一维的点评都遵循同一条内容纪律：先说可见或已知的依据，再依据学生当前需要使用“追问、提示、示范”中的一档，最后给一个可执行的最近动作。三档不是强制步骤；学生明确要求完整做法时可以直接示范，但应附带理解检查。

本提案的重点不是让 Lumi 一次说满六段，而是让每次会诊有稳定骨架：完整结果保留六维结构，当前对话优先展开最影响作品的 1—2 维，其余维度可简述为“暂未发现关键问题”或“证据不足，待补充”。

## 2. 共用会诊契约

### 2.1 触发与分流

- 适合触发：学生提交作品图、过程稿、方案板、界面状态图，并询问概念、审美、构图、文化表达或整体改进方向。
- 不适合触发：学生提交报错截图、参数截图，询问“怎么做”或“哪里错了”。这类问题进入证据式排错。
- 混合问题：先判断学生当下最急的问题。若作品方向与软件故障同时存在，先回应学生明确提出的主问题，再说明另一部分将用另一副面孔处理，不把两套结构混在一段话里。

### 2.2 证据边界

- “观察依据”只能来自当前作品中可见的事实、学生明确说过的信息或成长档案中可核对的历史记录。
- 不把推测写成事实。无法确认时使用“从当前截图只能看到……”“如果你的目标是……”“还需要一张……才能判断”等措辞。
- 静态图不能证明交互时序、响应速度或运行稳定性；版式缩略图不能证明实际阅读尺寸。证据不足时应索取状态图、短视频、参数或成品规格。
- 第六维引用成长档案时必须说清比较对象；没有历史记录就明确说明，不编造“比上次进步”。

### 2.3 渐进式话术

| 档位 | 使用时机 | 句式要求 |
| --- | --- | --- |
| 追问 | 关键意图、受众或条件尚不明确 | 一次只问一个会改变判断的关键问题，并说明为什么要问 |
| 提示 | 方向已基本明确，学生仍有自主调整空间 | 指出一条有依据的关系，给检查方法或小步尝试，不直接代做整套方案 |
| 示范 | 学生需要具体样例、已尝试仍卡住，或明确要求完整做法 | 给局部、可迁移的示范，随后要求学生解释选择或把方法改写到自己的方案中 |

## 3. 课程化变体一：数字交互文创设计

### 3.1 意图与信息（`intent_information`）

**本课检查要点**

- 学生能否用一句话说清“想让谁，通过什么互动，感受到或理解什么”。
- 文化内容是否进入“输入—反馈—含义”的关系，而不只是贴在画面表层的符号。
- 互动效果是否服务核心表达；技术效果多时，是否仍有一个主目标。
- 当前证据至少包含方案说明与一个关键状态图；仅有视觉效果图时，不推断互动含义。

**示例点评语句**

- 追问：“你希望观众结束这次互动后，最先带走的是哪一层——看懂一个文化信息、感到一种氛围，还是意识到自己的动作改变了作品？先定一个主目标，我再帮你看现有反馈有没有为它服务。”
- 提示：“从当前画面能确认输入已经引起视觉变化，但‘为什么要这样变化’还没有和主题连紧。先写一条‘动作—反馈—含义’的因果句，再用它删掉不服务主目标的效果。”
- 示范：“如果你要表达‘靠近才能看见被忽略的纹样’，可以先写成：观众靠近 → 纹样由模糊变清晰 → 解释文字最后出现。现在请你把这条关系换成自己的主题，看看三步里有没有一处只是炫技、没有传达信息。”

### 3.2 受众与场景（`audience_context`）

**本课检查要点**

- 作品面向单人还是多人，观众是驻足体验还是快速经过，是否需要零讲解上手。
- 展陈距离、屏幕位置、环境光线、声音条件与现场动线是否支持互动。
- 观众如何发现“这里可以互动”，首次反馈是否足够快且可理解。
- 是否考虑身高、行动范围、多人遮挡、声音干扰等真实使用差异。

**示例点评语句**

- 追问：“这件作品最可能出现在安静展厅、开放走廊，还是课堂展示？场景会直接决定提示要多明显、声音能不能承担主要反馈，我们先把这一点定下来。”
- 提示：“入口画面已经有主题标题，但从静态图还看不出观众会不会知道‘该做什么’。可以先做一个不靠教师解释的五秒测试：让同学站到作品前，看他能否找到第一个动作。”
- 示范：“如果场景是人流较快的走廊，首屏可以只保留一句动作提示和一个持续但克制的响应线索；观众一靠近就先得到即时反馈，主题信息随后展开。你可以请一位没听过方案的同学试一次，再记录他第一步做了什么。”

### 3.3 信息层级与视觉动线（`hierarchy_flow`）

**本课检查要点**

- 待机、发现、触发、反馈、结束或回到待机等状态是否可区分。
- 观众在每个状态中先看哪里、再看哪里；重要信息是否被粒子、动效或装饰抢走。
- 时间顺序是否替代了平面中的部分层级，关键变化是否出现得太快或同时发生。
- 静态截图不足以判断时序时，需要连续状态图或短视频，不凭一帧推断完整动线。

**示例点评语句**

- 追问：“你希望观众进入画面后的前三秒按什么顺序看到内容？先说‘第一眼、第二眼、互动后’三步，我再对照现在的状态安排。”
- 提示：“当前标题、主体图形和反馈光效同时很强，第一眼的落点不够稳定。先暂时关掉一组效果，只保留一个主视觉和一个互动提示，观察视线是否更容易进入。”
- 示范：“可以把节奏拆成：待机时只出现主视觉与轻提示；触发后主视觉先变化；变化稳定后再出现解释信息。请你用三张状态图排出这个顺序，不必先改完整工程。”

### 3.4 形式语言（`formal_language`）

**本课检查要点**

- 构图、色彩、字体、图形、动效与声音是否共同服务同一气质与文化语境。
- 互动反馈的运动方式是否有语义，而非所有元素都使用同一种随机变化。
- 传统文化视觉资源是否经过转译，避免只靠符号堆叠制造“文化感”。
- 不从静态图臆测声音与运动；缺少相应证据时明确请求补充。

**示例点评语句**

- 追问：“你想让这组视觉更接近庄重、亲近，还是带一点实验感？这个词会决定颜色、运动速度和字体该往同一个方向收，先选最重要的一个。”
- 提示：“画面里的纹样和字体已经指向传统语境，但高频闪动带来的情绪更偏科技演示，两者现在各说各话。可以先只调整运动节奏，看看不换素材能否让气质统一。”
- 示范：“若目标是‘克制而有仪式感’，可以保留低饱和底色，让纹样以缓慢显影回应靠近，标题只在关键节点出现。你再说明这三项中哪一项承载主题、哪两项只是配合，避免所有元素都抢主角。”

### 3.5 工艺与规范（`craft_standards`）

**本课检查要点**

- 输出尺寸、屏幕比例、分辨率、帧率和字体最小可读尺寸是否适配现场设备。
- 传感范围、反馈延迟、多人干扰、断开连接与回到待机的条件是否经过验证。
- 现场布线、声音播放、光照与设备摆位是否可实现且安全。
- 本维只检查作品可落地性；具体节点、参数或报错原因应转入证据式排错。

**示例点评语句**

- 追问：“最终展示用什么屏幕和输入设备，观众离它大约多远？没有这两个条件，我现在只能判断画面，不能判断字号、触发范围和反馈速度是否合适。”
- 提示：“方案已经写了触发动作，但还缺‘多久算有反应’和‘无人时怎样复位’。先把这两个条件写成可测试的数值或现象，再做现场测试。”
- 示范：“你可以先做一张最小验收表：一米内可触发、首次反馈在可接受时间内出现、连续三次触发不丢失、无人后能回到待机。具体阈值请按设备实测填写，再解释哪一项最影响体验。”

### 3.6 亮点与最近改进点（`strength_growth`）

**本课检查要点**

- 先指出一项有画面或行为依据的有效选择，再给一个最值得推进的最近动作。
- 有成长档案时，只比较同一学生可核对的前次方案、会诊或修改记录。
- 区分“新加了效果”和“表达、交互或实现真的更清楚了”，不以效果数量代替成长。
- 无历史记录时不做纵向判断，只写本轮亮点与下一步，并说明暂不能比较。

**示例点评语句**

- 追问：“你自己觉得这版相较上次，最实质的变化是什么——主题更清楚、观众更会操作，还是运行更稳定？我想先听你的判断，再对照成长档案里的修改记录。”
- 提示：“成长档案里可以核对到，你上次主要靠说明文字解释互动；这次已经让画面反馈承担了一部分说明，这是有效进步。最近一步先别继续加效果，找一位不知情同学测试他能否读懂这层关系。”
- 示范：“可以把本维写成：‘亮点：动作与主题第一次形成了可见联系；相较上次：从文字解释推进到视觉反馈；最近动作：用一次无讲解测试验证观众是否读懂。’然后请你补一句：如果测试失败，你最先改哪一处？”

## 4. 课程化变体二：版式设计

### 4.1 意图与信息（`intent_information`）

**本课检查要点**

- 版面要传达的核心信息是否明确，主标题、辅助信息与正文各自承担什么任务。
- 内容是否经过取舍和分组，而非把所有文字等量摆入画面。
- 视觉重点是否与传播目标一致；装饰是否抢走真正需要被读到的信息。
- 当前证据至少包含完整页面与可读文字；文字无法辨认时不推断内容结构。

**示例点评语句**

- 追问：“如果读者只看三秒，你最希望他记住哪一句或哪一个信息？先选唯一的第一信息，我再帮你判断现在的字号和位置有没有把它托起来。”
- 提示：“从当前页面看，标题、日期和说明文字的视觉重量很接近，内容已经分组，但主次还没有拉开。先只改字号或字重中的一个变量，做一版强弱更明确的对照。”
- 示范：“例如把核心标题设为唯一最大层级，日期与地点合成第二组，说明文字回到稳定正文宽度。请你遮住图片只看文字，复述一次阅读顺序；如果顺序仍不清楚，就继续减层级而不是加装饰。”

### 4.2 受众与场景（`audience_context`）

**本课检查要点**

- 作品给谁看、在哪里看、看多久：远距离海报、近距离书页或手机界面需要不同策略。
- 实际尺寸、观看距离、环境光与载体是否支持当前字号、对比度和信息密度。
- 受众已有知识与阅读习惯是否影响术语、图片与文字的比例。
- 没有成品尺寸或展示情境时，只能评价相对关系，不能断言实际可读性。

**示例点评语句**

- 追问：“这张版面最终是 A3 海报、书页，还是手机长图？同一套层级放到不同载体上会完全不同，我们先确定读者在哪里、离多远看。”
- 提示：“缩略图里标题能被识别，但正文是否可读还不能确认。请按最终尺寸打印一张，或在目标设备上以 100% 比例查看，再记录正常距离下最先读到和最难读到的内容。”
- 示范：“如果它是走廊里的 A3 海报，可以先按‘两米看到主题、一米看到时间地点、走近再读说明’来分层。你用这三个距离检查一次，并告诉我哪一层没有在预期距离出现。”

### 4.3 信息层级与视觉动线（`hierarchy_flow`）

**本课检查要点**

- 标题、副标题、正文、注释等层级能否稳定区分，阅读顺序是否符合内容逻辑。
- 对齐、间距、分栏与栅格是否建立关系，视线是否在关键位置中断或绕行。
- 图片与文字的先后关系是否有意安排，留白是否帮助分组与停顿。
- 层级判断需要完整页面；局部截图不得代替对整页动线的判断。

**示例点评语句**

- 追问：“你预设的阅读顺序是什么？请只说前三步，例如‘标题—主图—时间’，我会按这个顺序检查对齐、距离和视觉重量。”
- 提示：“标题与主图已经形成第一组，但正文和时间离得同样近，读者容易把它们误认成同一层。先只调整组间距，不改字体，看看分组关系能否清楚起来。”
- 示范：“可以先画出三条不可见的对齐线：标题与正文左边线、主图边界线、时间信息的起点线；再用组内小间距、组间大间距建立节奏。做完后把页面缩小，检查三组是否仍能一眼分开。”

### 4.4 形式语言（`formal_language`）

**本课检查要点**

- 字体、字重、字号、行距、字距、色彩、图形与图像风格是否共同支持内容气质。
- 字体种类与强调手段是否克制，重复规则是否足以形成统一性。
- 留白、比例、节奏与对比是否有目的，而非为了“填满”或追逐某种风格表象。
- 涉及字体出处与授权时不作无证据判断，必要时提示学生核对来源。

**示例点评语句**

- 追问：“你希望它给人的第一感受更偏理性秩序、轻松亲近，还是强烈实验？先定一个主气质，我们再判断现在的字体和留白是不是朝同一方向用力。”
- 提示：“当前两种字体已经能区分标题和正文，但颜色、描边和倾斜又各自承担强调，强调手段有些分散。先保留一种主强调，其余回到基础状态，看主题是否反而更集中。”
- 示范：“如果目标是理性秩序，可以让栅格和字号对比承担主要表现，色彩只负责一个重点；标题用明确字重，正文保持稳定行距。你再指出哪条规则会在下一页继续重复，以验证这不是只对一页有效的装饰。”

### 4.5 工艺与规范（`craft_standards`）

**本课检查要点**

- 成品尺寸、出血、安全区、折页或装订位置是否明确，关键信息是否避开裁切与装订风险。
- 图片分辨率、色彩模式、黑色文字、字体嵌入或转曲等交付条件是否按实际输出方式检查。
- 数字发布时检查目标像素尺寸、不同屏幕比例与压缩后的清晰度。
- 本维只提出规范检查与验证动作；具体软件故障转入证据式排错。

**示例点评语句**

- 追问：“这份版面最终要印刷、屏幕发布，还是两者都要？先确认交付方式，我才能判断出血、图片精度和色彩设置里哪些是当前必须检查的。”
- 提示：“画面内容已经接近定稿，但边缘元素离裁切位置很近。先在文件中显示成品线、出血线和安全区，只检查关键信息是否越界，不急着继续微调风格。”
- 示范：“印刷稿可以先做四项交付前检查：尺寸与出血、图片有效分辨率、色彩模式、字体与链接资源。请你逐项写‘已确认/待确认’及证据，不要只凭预览画面判断已经可印。”

### 4.6 亮点与最近改进点（`strength_growth`）

**本课检查要点**

- 亮点必须落到具体关系，如层级更清楚、对齐更稳定、留白更有节奏，而非只说“好看”。
- 有成长档案时，比较同一学生前后版本中可见的改变，并说明改变为何有效。
- 最近动作只选一项最影响阅读或表达的问题，避免列成长清单压垮学生。
- 无历史记录时明确无法比较，只评价本轮证据与下一步。

**示例点评语句**

- 追问：“你认为这版相较上次，哪个改动真正改变了阅读顺序？先别说‘更好看’，请指出一个字号、位置或间距关系。”
- 提示：“成长档案里的上一版中，标题和正文都压在主图边缘；这版已经用留白把两组分开，第一层更稳定。最近一步只处理时间信息，让它进入第二层，不要同时再换字体。”
- 示范：“可以把本维写成：‘亮点：主标题与主图形成明确入口；相较上次：组间距拉开后阅读顺序更稳定；最近动作：把时间信息并入第二层并做一次缩略图检查。’请你解释为什么先改时间，而不是先加新的图形元素。”
