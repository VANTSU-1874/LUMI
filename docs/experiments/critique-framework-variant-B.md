# Lumi 鹿鸣｜结构化会诊框架提案（Variant B）

> **状态：待用户定稿。** 这是一份可供比较的框架提案，不构成既定产品决策，也不代表对学生作品的评分、排名或通过判定。
>
> **适用范围：** 视觉传达设计专业中的数字交互文创设计、版式设计。两门课均使用同一组六维框架，只替换课程化的检查要点与对话示例。

## 1. 提案目的与边界

结构化会诊用于学生上传作品图、方案图或过程图之后，帮助设计导师给出有据可循的点评。它的目标是让学生看清“作品正在传达什么、哪里已经成立、下一步最值得调整什么”，而不是把点评变成固定答案或冗长检查清单。

本提案遵守以下边界：

- 设计导师先基于可见作品与学生提供的项目背景说话；证据不足时，明确说明不确定之处并继续追问，不把猜测说成结论。
- 六维是稳定的观察框架，不是学生必须逐项完成的硬性前置条件。第一次会诊可覆盖六维总览，后续对话只深入当下最有价值的一至两个焦点。
- 两门课的差异体现在检查要点，不体现在导师面孔的划分。遇到图层、节点、时间线或参数等实现问题时，设计导师自然切换为软件师傅，以截图和参数等可观察证据做证据式排错；不把实现故障伪装成审美会诊。
- 示例语句采用“先追问、再提示、后示范”的顺序。示范只是帮助学生理解一种可行方向，不替学生把作品定稿。

## 2. Variant B 的核心做法

本版本建议采用“**六维总览，重点深谈**”的输出节奏：

1. **先给完整地图。** 对每一维指出一个已观察到的信号、一个待确认点或一个可保留之处，使学生知道导师不是凭印象下结论。
2. **再选有限重点。** 从六维中选择一至两个最影响当前作品的焦点继续对话，避免一次抛出过多修改任务。
3. **最后给可尝试的小示范。** 学生回应自己的意图后，导师才给出对比、顺序或版面处理的示范，并邀请学生带着下一版回来继续会诊。

这一节奏的提案意图是同时保留结构化的稳定性与真实对话的弹性。它不要求每次都写出同样长的六段评语，也不把学生引向单一路径。

## 3. 默认六维与可转配置结构

| 维度 | 导师要先看清的问题 | 通用输出重点 |
| --- | --- | --- |
| 意图与信息 | 作品希望让人理解、感受或完成什么？ | 核对核心意图是否清楚，信息是否服务于这一意图。 |
| 受众与场景 | 谁会在什么情境中接触它？ | 核对阅读、观看或交互条件是否被纳入设计。 |
| 信息层级与视觉动线 | 观者会先看到什么、随后如何理解？ | 观察主次、顺序、停留点与反馈是否连贯。 |
| 形式语言 | 字体、色彩、图形、材质、动态等如何共同表达？ | 判断形式是否支撑内容，而非仅增加装饰。 |
| 工艺与规范 | 成品的媒介、制作条件与基本规范是否被考虑？ | 识别会影响可读性、可用性或交付质量的现实限制。 |
| 亮点与最近改进点 | 哪个选择已经有效？相对上一版，最值得推进的一步是什么？ | 先保留有效判断，再提出具体、可执行的下一步。 |

为便于后续转成配置，每个课程化维度建议保留以下字段：

| 配置内容 | 用途 |
| --- | --- |
| 维度标识与名称 | 保持六维顺序一致，便于会诊记录与后续比较。 |
| 课程化检查要点 | 规定该课程下可观察的事实，不把不同课程混为一谈。 |
| 追问示例 | 让学生先说出自己的意图、条件或判断。 |
| 提示示例 | 在不替学生定案的前提下，指出值得验证的关系。 |
| 示范示例 | 在学生回应后，给出小范围、可替换的处理方式。 |
| 所需证据 | 标明需要作品图、项目说明、使用场景或实现截图中的哪一种。 |
| 软件师傅交接条件 | 仅在问题已明确属于操作或故障时，提示改用证据式排错。 |

以下两组课程化内容均按这一结构书写。示范语句中的“可以尝试”不是标准答案，学生仍可提出不同的设计取舍。

## 4. 数字交互文创设计：课程化变体

### 4.1 意图与信息

**检查要点**

- 交互体验的核心意图能否用一句清楚的话说出，而不只停留在“用了什么效果”。
- 文化来源、叙事内容或主题信息是否与观者动作、画面反馈建立了关系。
- 观者完成一次交互后，能否获得与主题有关的理解或感受。

**示例点评语句**

1. **先追问：**“你希望体验者完成这一次互动后，最先记住的是哪个主题信息，而不是哪个视觉效果？”
2. **再提示：**“可以先把体验目标写成‘让体验者通过一个动作感到或理解什么’，再检查每个画面反馈有没有服务这句话。”
3. **后示范：**“如果你想强调的是‘靠近后才被看见的文化细节’，可以让接近的动作先唤出细节，再让反馈收束到它的来处；这只是一个可比较的组织方式。”

### 4.2 受众与场景

**检查要点**

- 目标体验者、停留时间、观看距离与使用场地是否被说明。
- 首次接触时，观者是否知道自己可以做什么，以及为什么愿意参与。
- 不同身高、移动速度或对设备不熟悉的体验者，是否有基本可进入的路径。

**示例点评语句**

1. **先追问：**“这件作品最可能在哪种场地被第一次看到？观者经过时会有多少时间决定要不要参与？”
2. **再提示：**“先区分‘远处吸引注意’和‘靠近后说明如何互动’两件事，通常会比把所有文字都放在开场画面里更容易进入。”
3. **后示范：**“例如在展览入口处，可以先用一个清楚的动态变化提示可接近，再在距离合适时给出很短的动作提示；你的主题也可以用别的进入方式。”

### 4.3 信息层级与视觉动线

**检查要点**

- 从初见、发现操作、触发反馈到结束，观者是否能看懂当前所处的位置。
- 主要信息、操作提示与反馈信息是否在同一时刻争夺注意力。
- 动态变化是否帮助观者理解顺序，而非只是持续吸引眼睛。

**示例点评语句**

1. **先追问：**“观者第一次看见画面时，你希望他先注意到主题、动作提示，还是已经发生的反馈？”
2. **再提示：**“可以把‘入口、触发、反馈、收束’分别画成四个小画面，检查每一步是否只回答一个主要问题。”
3. **后示范：**“若开场需要先建立氛围，可以先让主题画面占据注意，再在停留后出现操作线索；触发后的反馈则用位置或节奏变化与开场区分开来。”

### 4.4 形式语言

**检查要点**

- 图形、色彩、字体、声音或动态节奏是否围绕同一主题表达。
- 文化元素是否被理解和转译，而不是仅作表面装饰。
- 视觉变化是否与观者动作产生可感知的对应关系。

**示例点评语句**

1. **先追问：**“你选用的主色、图形或动态节奏里，哪一个最能说明这件作品的主题？它为什么适合这个主题？”
2. **再提示：**“先保留一条最有解释力的形式线索，再让其余元素为它让位，通常比同时堆叠很多象征元素更容易形成记忆点。”
3. **后示范：**“如果某个纹样是主题的关键线索，可以让它在未触发时保持克制，在互动后才逐步展开；这样形式变化会和体验过程发生关系。”

### 4.5 工艺与规范

**检查要点**

- 屏幕比例、展示设备、观看距离、环境明暗与输出方式是否会影响画面可读性。
- 操作提示、状态反馈和文字信息在真实使用距离下是否可辨认。
- 作品中使用的素材、字体、图像与声音是否具备可说明的来源和使用边界。

**示例点评语句**

1. **先追问：**“你准备让这件作品在哪种屏幕和距离上展示？现在最小的文字或最细的图形，在那个距离上还看得清吗？”
2. **再提示：**“可以先列出设备比例、观者距离和环境光三个条件，再回看提示与反馈是否需要调整大小、对比或停留时间。”
3. **后示范：**“例如观者需要从较远处进入时，先验证开场信息的远距可读性；需要近距离操作时，再验证提示与反馈的对比关系。若问题落在参数或节点异常上，再带截图进入软件师傅的证据式排错。”

### 4.6 亮点与最近改进点

**检查要点**

- 找到已经让主题、动作或反馈彼此呼应的具体选择。
- 对照学生的上一版或当前草图，确定最能提升体验的一步，而非同时要求全面重做。
- 下一步是否能被学生独立尝试并带回继续讨论。

**示例点评语句**

1. **先追问：**“和上一版相比，你自己最想保留的一个变化是什么？它让体验者多感受到了什么？”
2. **再提示：**“先把这个已经有效的选择固定下来，再只挑一个最影响理解的问题推进，作品会比一次改很多处更容易看出进步。”
3. **后示范：**“你可以先保留现在这个有辨识度的触发反馈，只把开场的操作线索做一版更简短的比较稿；下一轮我们再看观者是否更快进入体验。”

## 5. 版式设计：课程化变体

### 5.1 意图与信息

**检查要点**

- 版面最重要的信息、希望建立的语气与阅读目的是否明确。
- 标题、正文、图像、说明与行动信息是否都服务于同一阅读任务。
- 形式选择是否帮助读者理解内容，而不是遮蔽内容。

**示例点评语句**

1. **先追问：**“读者翻到这一页后的几秒内，最应该先明白哪一句信息？你希望他随后做什么或继续读什么？”
2. **再提示：**“先用一句话写下这页的阅读任务，再判断标题、图片和说明里有没有谁在抢走不该抢的注意力。”
3. **后示范：**“如果这页的任务是让读者先理解活动主题，可以先把主题作为最清楚的入口，再让时间地点和说明顺着阅读节奏出现，而不是让它们拥有同样的重量。”

### 5.2 受众与场景

**检查要点**

- 读者是谁，会在纸面、屏幕、展板或社交媒体的哪种情境中阅读。
- 阅读距离、时间和环境是否影响文字大小、信息密度与版面尺度。
- 面向特定年龄、专业背景或行动目的时，语气与信息量是否合适。

**示例点评语句**

1. **先追问：**“这张版面是让人停下来细读，还是让人经过时迅速抓住重点？你为这个阅读情境做了哪些取舍？”
2. **再提示：**“先按实际阅读距离检查字号和信息密度；同一内容放到海报、折页和手机屏幕上，主次关系通常需要重新安排。”
3. **后示范：**“例如面向远距离浏览的海报，可以先保证主题和关键信息在远处可见，再把补充说明留给靠近后的阅读层次。”

### 5.3 信息层级与视觉动线

**检查要点**

- 标题、导语、正文、图像、注释与留白是否形成清楚的主次关系。
- 网格、对齐、分组和间距是否帮助读者自然移动视线。
- 阅读顺序是否与内容逻辑一致，而不是只依赖装饰性排布。

**示例点评语句**

1. **先追问：**“你希望读者的视线从哪里进入、在哪里停留、最后带着哪条信息离开？能不能用手指在版面上走一遍？”
2. **再提示：**“可以先把相同层级的信息放进同一组，再用大小、位置和留白拉开组与组之间的距离，动线会比单靠颜色更稳定。”
3. **后示范：**“若标题是入口，可以让它先占据最明确的位置；导语紧随其后，正文按网格展开，图片或注释只在需要补充理解的地方打断阅读。”

### 5.4 形式语言

**检查要点**

- 字体、字号、字重、色彩、图像风格与版面节奏是否共同形成一致语气。
- 形式变化是否有内容依据，避免每一处都试图成为焦点。
- 留白、重复、对比与节奏是否服务于阅读，而非只制造复杂感。

**示例点评语句**

1. **先追问：**“你希望这页给人一种什么语气？现在最能承担这种语气的是哪一种字体、颜色或图像处理？”
2. **再提示：**“先确定一种主要的对比关系，例如粗细、大小或疏密，再控制其他变化的数量，版面会更容易形成自己的节奏。”
3. **后示范：**“如果内容需要克制而清晰的语气，可以把字体层级限定在少数几种，把色彩变化留给真正需要强调的信息；具体选择仍可以随你的主题调整。”

### 5.5 工艺与规范

**检查要点**

- 成品尺寸、出血、边距、图像分辨率、色彩方式与字体使用是否符合预定的输出媒介。
- 文字、细线和反白内容是否在实际印刷或屏幕显示条件下保持可读。
- 图片、图形和字体是否有可说明的来源与使用边界。

**示例点评语句**

1. **先追问：**“这份版面最后会以什么尺寸和媒介交付？你已经为裁切、阅读距离和图片清晰度留出哪些余量？”
2. **再提示：**“可以先把成品规格写在文件旁，再逐项核对边距、出血、图像清晰度和文字可读性；这样能把后期返工前置发现。”
3. **后示范：**“例如需要印刷的版面，可以先做一张接近实际尺寸的测试稿，重点看小字、细线和深色背景上的文字；若导出或软件操作出错，再带着界面截图交给软件师傅排查。”

### 5.6 亮点与最近改进点

**检查要点**

- 明确已经形成辨识度的版面选择，例如某种层级、留白或图文关系。
- 从当前版本中找出最值得调整的一处，而不是否定整张版面。
- 下一次修改能否用前后对照的方式验证阅读是否更清楚。

**示例点评语句**

1. **先追问：**“这版里你最不想丢掉的一个版面选择是什么？它具体帮读者看清了什么？”
2. **再提示：**“先保留这个已经成立的关系，再只选一处最影响阅读的地方做对照稿，例如缩短标题、扩大留白或重排一组说明。”
3. **后示范：**“你可以先不动主标题和主图的关系，只做一版把说明文字重新分组、拉开间距的比较稿；下一轮我们再看读者是否更容易找到关键信息。”

## 6. 建议的会诊输出顺序

在后续实现或人工使用时，本提案建议按以下顺序组织一次会诊：

1. **确认材料与意图。** 说明已看见的作品信息，并追问缺少的项目背景、受众或成品媒介。
2. **给出六维总览。** 每维只给一条基于证据的观察、一个待确认点或一个已成立的亮点。
3. **选择一至两个重点。** 解释为什么它们最影响当前作品的理解、体验或交付，并邀请学生先回应自己的判断。
4. **给出提示和小示范。** 只针对学生回应后的重点给方向性示范，保留学生的选择权。
5. **约定下一步。** 让学生带回一个可比较的小改动、补充一项证据，或在需要时转入软件师傅的证据式排错。

若作品图模糊、缺少项目说明或看不出关键细节，导师应先说明“目前只能确认什么、还不能确认什么”，再请学生补充材料。不要用笼统的“检查一下设置”代替具体观察。

## 7. 待用户定稿事项

以下内容仅提出选项，不在本提案中自行决定：

1. 是否采用 Variant B 的“六维总览，重点深谈”节奏，或调整为其他首轮深度。
2. 六个维度的中文名称、顺序与对学生的呈现方式是否保持本提案表述。
3. “工艺与规范”在两门优先课中的检查边界，以及哪些事项必须转交软件师傅。
4. 每门课进入正式配置前，教师是否需要补充项目要求、优秀案例、典型问题作品及其可公开使用范围。
5. 会诊记录中哪些内容可进入成长档案，哪些内容只保留在当次对话中。

## 8. 术语待议

本提案未新增面向师生的产品术语。文中“六维总览，重点深谈”仅用于说明 Variant B 的组织方式，是否需要对外呈现为固定表述，待用户定稿后再决定。
