# 从单课程门禁智能体转向专业级设计导师，并更名 Lumi 鹿鸣

原方案"通感阶梯"是数字交互文创设计单门课程的流程管控智能体（入学诊断、六元逻辑门禁、三级提示、迁移挑战）。V1–V3 开发实践表明：单门课程对学生的价值太窄；门禁式体验会让学生绕开系统直接使用通用聊天 AI；"不过关不给答案"的管控与"深度自适应引导"相比是下策。因此决定：拆除答案门禁（commit 3dc7d21），转向覆盖视觉传达设计专业 11 门核心课程、按问题类型切换"设计导师/软件师傅"双面孔的成长导师，并更名 **Lumi 鹿鸣**（Lumi=拉丁语"光"；鹿鸣宴为登科学子所设）。

## Considered Options

- **保留门禁、扩大课程覆盖**：被否——门禁是体验问题的根源，扩覆盖不解决"学生绕道"。
- **纯通用设计 AI（不锚定专业）**：被否——教学深度叙事塌陷，比赛语境下等同"套壳聊天机器人"。
- **保留"通感阶梯"名并重新诠释**：被否——名字与交互课强绑定，且发音不符合"简单顺口"的命名要求。

## Consequences

- 旧设计的教学法精华以柔性形式回收：诊断画像→成长档案，迁移挑战→举一反三动作，六元卡精神→结构化会诊，信号链诊断→证据式排错。
- 旧 spec 中的门禁、L1–L4 等级、路径规划器、重指标教师分析台不再实现；相应旧文档标记为已取代。
- "AI 代做"的质疑改由"导师品格"（苏格拉底式软原则）+ 教师洞察台可见性承接，评审答辩需按此口径准备。
