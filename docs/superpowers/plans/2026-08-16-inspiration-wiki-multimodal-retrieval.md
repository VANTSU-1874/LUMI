# Inspiration Wiki 站内多模态检索

## 目标

以 177 条当前正式案例为唯一索引集合，为已登录学生提供文字找图、图片找图和图文组合检索。保持现有 Browse、Search、Preview 与撤下机制；不接入 Lumi 回答链，不启用 R2，不调用外部 Embedding Provider。

## 边界

- 索引工件绑定完整 Release 集合、源生产包摘要、受控预览 SHA、编码器版本和用户授权引用。
- 图像只在本地用 Sharp 解码为固定维度的空间色彩与亮度特征；文字只在本地编码为确定性的 Unicode n-gram 特征。
- 图文组合查询融合两个通道的分数；这不是 CLIP、视觉语言模型或外部语义 Embedding，不得如此宣传。
- 每次查询把索引结果与最新 Current Page 事件求交集；作品撤下后即使旧索引仍在，也不能返回该作品。
- 索引缺失或摘要不一致时，文字查询降级到原有搜索；图片查询不回退远程 URL，也不返回未审核材料。
- 完整索引包含登录后才可见的案例投影，不进入公开 Git 历史；它作为内容寻址的受控发布侧车并入签名构建包。
- 发布和回滚以同一 Git release 与侧车的原子切换为激活边界，不修改历史 Formal Release 的 `embedding`、`wikiRetrieval` 或 `lumiRetrieval` 字段。

## 验收

1. 合同与工件摘要复算一致，177 个 publicId/asset SHA 唯一且全部来自正式发布包。
2. 未登录请求被拒绝；上传只接受 8 MB 内 JPG/PNG/WebP，实际解码失败时安全拒绝。
3. 文字找图、图片找图、图文组合三种模式均返回受控预览、来源和署名。
4. 索引缺失时原有文字检索可用；撤下项无法从多模态结果返回。
5. 桌面与 320/375/414/768px 下上传、清除、加载、错误和结果状态无重叠或横向溢出。
6. 生产切换后以真实已登录学生完成现场查询，并保留状态、失败降级和回滚证据。
