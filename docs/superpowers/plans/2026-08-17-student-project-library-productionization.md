# 学生端项目与文件库正式化实施计划

日期：2026-08-17  
状态：执行中  
范围：已登录学生端 `/student` 内的“项目”和“文件库”  
不在范围：登录、灵感 Wiki、多模态检索、教师端、Lumi 回答策略、对象存储迁移

## 1. 当前真相

- 学生对话已经由 `design_project_tasks`、`/api/agent/tasks` 和 assistant-ui 远程任务适配器持久化；它就是当前账户级设计任务实体。
- 侧边栏“项目”另用 `localStorage` 保存 `LabProject`，没有绑定真实任务、消息或项目简报，形成了第二套假项目。
- “文件库”只读 `localStorage` 中的演示输出；写入函数没有接入实际发送流程，图片仍指向固定演示素材。
- 学生在对话中上传的 PNG/JPEG/WebP 已由 `agent_artwork_attachments` 和私有媒体端点受控持久化，但尚未投影到文件库。

## 2. 目标合同

### 项目

- `design_project_tasks` 明确回归“对话线程”语义；新增独立项目容器，保存名称、图标、颜色、项目说明、状态和项目专属记忆模式。
- 一个项目可包含多条既有或新建对话；支持把对话移入、移出项目，且不改变对话 ID 或历史。
- 项目文件、项目说明和项目内对话摘要构成项目上下文，只对该项目内回答生效。
- 支持项目新建、打开、重命名、归档/恢复和删除；删除项目按明确确认同时删除其项目文件和项目内对话。
- 所有列表和写操作必须经过学生会话与 `(student_id, class_id)` 所有权校验。

### 文件库

- 文件库统一展示上传文件、对话附件和 Lumi 生成文件；来源必须明确标注。
- 支持搜索、来源与类型筛选、下载、删除、从文件库添加到对话，并展示存储用量。
- 独立上传使用新的账户级私有资产记录；对话附件保留原消息所有权，不因“从文件库移除”破坏聊天历史或教师评图证据。
- 预览与下载只返回鉴权后的同源 URL，不向浏览器泄露磁盘路径。
- 独立上传可以删除；对话附件第一阶段只允许查看和下载，删除仍回到原对话的证据生命周期。
- 默认私有、`Cache-Control: private, no-store`，跨学生访问返回 404。

## 3. 实施阶段

### 阶段 A：合同与持久化

1. 新增 `student_library_assets` 表与迁移，保存所有者、可选任务、来源、文件名、MIME、尺寸、字节、SHA-256、受控存储路径和时间。
2. 新增文件库 Zod 合同、服务层和私有文件解析器。
3. 增加列表、上传、预览/下载、删除 API；限制类型、5 MB、像素上限、文件魔数、解码与哈希。

### 阶段 B：真实项目接线

1. 删除 UI 对 `LabProject` localStorage 模型的依赖，不删除服务器任务或历史记录。
2. 项目页复用 `/api/agent/tasks`，显示活动与已归档任务。
3. 新建/打开项目直接调用 assistant-ui 任务适配器并切换到对应任务。

### 阶段 C：真实文件库接线

1. 文件库读取服务器资产，显示缩略图、文件名、来源项目、类型、尺寸、大小和时间。
2. 增加受控上传、类型筛选、下载和独立上传删除。
3. 加载、空态、错误、上传中、删除确认和移动端布局沿用当前 Lumi 工作台视觉系统。

### 阶段 D：验证与发布门

1. 合同/服务测试：所有权、跨账号隔离、类型/大小/魔数、路径穿越、哈希、删除语义。
2. API 集成测试：未登录、教师身份、学生 A/B、上传/读取/删除、对话附件投影。
3. 组件测试：项目任务接线、文件库有图/空态/错误、按钮和键盘行为。
4. 浏览器验收：同一学生刷新恢复、第二账号隔离、桌面和移动端；确认对话与项目身份一致。
5. 生产发布前单独复核迁移链、磁盘容量、备份、回滚和现有学生对话回归。

## 4. 验收标准

- 清空浏览器 `localStorage` 后，项目和文件仍可从服务器恢复。
- 同一学生换浏览器登录后看到相同项目与文件；另一学生看不到。
- 项目页打开的任务 ID 与对话当前远程任务 ID 一致。
- 对话上传图片自动出现在文件库；独立上传可预览、下载和删除。
- 删除独立上传后，数据库记录与私有文件一致清理；对话附件不能被文件库误删。
- 所有媒体端点不返回本地路径或远程定位符，并带 `private, no-store`、`nosniff`。
- 登录、灵感 Wiki、Browse/Search/Preview 与当前对话历史无回归。

## 5. 明确延期

- PDF、DOCX、PPTX、PSD、AI 等文档/源文件在图像闭环验收后另行扩展，届时为每种格式建立独立校验与安全预览策略。
- R2、公开分享、教师共享、协作项目和 Lumi 自动引用不在本计划内。
