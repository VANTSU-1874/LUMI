# 会诊框架修订计划：六维 → 五维一收（for Codex 内容会话）

> **执行者**：内容轨道会话（`feature/lumi-content` worktree）。**不是**重建会话。
>
> **对重建的影响：零。** 本计划只改 `docs/**` 下的提案文档，不碰任何应用代码，与 `feature/tonggan-mvp` 上的重建工作路径无交集。重建会话无需知晓本计划，也不必同步。
>
> **背景**：P2 已跑完模型 A/B（协议见 `2026-07-18-model-ab-test-protocol.md`），产出 variant-A / variant-B 两份**六维**提案。随后用户定稿了框架骨架，六维改为**五维一收**。两份旧稿不作废，作为素材来源。
>
> **框架定义以 `CONTEXT.md` 的"会诊五维"与"收束"两条为唯一准绳**，本计划不重复定义，只讲怎么改。

## 改了什么（三点）

1. **合并**：旧「意图与信息」+「受众与场景」→ 新「**目标**」（要传达什么 × 给谁在什么场景）。
2. **新增**：「**创意转译**」——用什么办法把抽象意思变成这个形象。这是视觉传达专业的核心环节，旧六维完全没有专属位置（只在「形式语言」里被提过一句）。
3. **降级**：旧第六维「亮点与最近改进点」不再是并列维度，改为每次会诊必到的「**收束**」。它横跨五维，因此**只深谈 1–2 维时也必须输出**——这是它降级的全部意义，实现与文案都要守住。

维度总数不变（5 个观察维 + 1 个收尾），改动是"用最该有的一维换掉最勉强的一处拆分，并修好一个结构错误"。

## Task R2：新维度「创意转译」的课程化内容

这是本次修订唯一的**新写**部分，也是最需要专业判断的部分。各课的转译对象参考（**两门优先课必写，其余先留骨架**）：

| 课程 | 「创意转译」这一维在问什么 |
| --- | --- |
| **数字交互文创设计**（优先） | 观众的动作如何成为意义的载体：输入 → 判断与映射 → 输出这条链是否成立，文化意图是否真的被这条链承载，而非贴在画面表层。**旧方案的六元交互逻辑在此维复活**——可直接从已取代的 2026-07-11 旧 spec 回收内容 |
| **版式设计**（优先） | 内容的逻辑结构如何变成视觉结构：用什么版面策略（对比、网格、图文关系、留白节奏）承载内容本身的层次与语气 |
| 图形创意 | 同构、置换、正负形、异影等转译手法的选择与贴切度 |
| IP 形象设计 | 性格、文化特征如何外化为造型语言（比例、剪影、符号取舍） |
| 品牌与 VI 设计 | 品牌概念如何收敛为一个可延展、可复用的标志与系统 |
| 书籍设计 | 内容叙事如何变成翻阅节奏、开本、材质与信息编排 |
| 界面设计 | 任务流程如何变成信息架构与交互隐喻 |

- [ ] 两门优先课的「创意转译」各写：检查要点（3–4 条，全部可观察或可追问）+ 追问/提示/示范三条示例语句
- [ ] 示例语句遵守导师品格；**示范之后必须带理解检查或迁移动作**
- [ ] 数字交互文创课的这一维，回收旧 spec 的六元交互逻辑内容（注明来源"旧课程设计文档"）
