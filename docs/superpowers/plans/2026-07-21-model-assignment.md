# 模型分配单（GPT-5.6，Pro 账户）

> **用途**：横跨今天三份计划（v4 接入 / 嵌入收尾 / 部署执行令）的模型与推理强度分配。Codex 执行任一任务时按本单选模型。
>
> **账户**：用户 Pro 订阅 → Codex 里 Sol / Terra / Luna 全可选、各设推理强度，max 与 ultra 均可用。
>
> **通用规则**：① 高危可审计任务用 **Sol + max**，**不用 ultra**（ultra 是 4 子智能体并行黑箱，与"每步可控、遇取舍停下"纪律冲突）；② 界面/视觉打磨用 **Sol**（GPT-5.6 设计判断力是卖点，Lumi 界面要经得起五维会诊）；③ 机械、见分晓快的活用 **Luna** 省额度；④ 任何触发"用 Luna 降级重试"框的多为网络安全防护误拦截，不是故障——取消、换措辞或主力模型重发。

## 部署执行令

| 任务 | 模型 + 强度 | 理由 |
|---|---|---|
| 机器身份核对、体检（SSH、free/df、备份 Caddy） | **Luna** | 机械命令，见分晓快 |
| 部署（拉代码、build、迁移种子、systemd） | **Terra** | 有模式可循，中等 |
| Caddy 域名接入、改配置 | **Sol + max** | 改错影响同机现有站点，高危 |
| runbook、备份 cron | **Terra** | 文档/脚本 |

## 嵌入收尾

| 任务 | 模型 + 强度 | 理由 |
|---|---|---|
| Task 1 现网测 /embeddings | **Luna** | 通不通一试便知 |
| Task 2 配置解耦 + 单测 | **Terra** | 常规改动 |
| Task 3 检索链路验证 | **Luna** | 抽查跑通即可 |
| Task 4 降级行为确认 | **Terra** | 逻辑中等 |

## v4 assistant-ui 接入

| 任务 | 模型 + 强度 | 理由 |
|---|---|---|
| Task 1 对话运行时接编排（停止/重试/工具 UI） | **Sol** | 接线复杂、易错 |
| Task 2 后端端点 + message 表 migration + 回填脚本 | **Sol + max** | 迁移/回填改错难回滚，高危 |
| Task 3 适配层 + 消息转换 + round-trip 测试 | **Sol + max** | 技术核心，转换错则历史损坏 |
| Task 4 自动标题 | **Terra** | 常规 |
| Task 5 归档 + 收口 | **Terra** | 常规 |
| Task 5 端到端手工验证 | **Luna** | 照单点检 |
| 五维会诊卡视觉、界面打磨（贯穿 Task 1/3 的 UI 面） | **Sol** | 设计判断力，界面要经得起评委 |

> 备注：Pro 在 ChatGPT 侧另有 Sol Pro 更高质量档；若 Codex 模型菜单出现，可用于最难的 Task 2/3，否则 Sol + max 已足够。
