## D-017 预置故事线

- 角色：视觉传达设计专业二年级学生；匿名编号只用于演示。
- 课程：数字交互文创设计。
- 作品设定：石刻纹样交互展墙草图；观众靠近时纹样逐步显影。
- 能力设定：能画基本状态图；在 DigiShow 中看到输入数值。
- 困难设定：说清文化意图、参与行为与反馈关系，并确认数值是否参与 TouchDesigner 画面计算。
- 历史设定：上一轮只有文字说明；本轮已画“靠近—显影”三个状态，仍缺无讲解体验记录。

以上都是比赛故事线。只有 seed 合入并在页面成功读取后，才可称为系统中的**预置历史**；无论是否入库，都不是学生实证。

## 诚实替代原则

- 模型不可用时只展示实际检索到的带来源语料；静态卡只称“预置说明材料”。
- 图片、软件截图或上传链路不可用时不作视觉判断，用预置说明材料解释预期结构。
- 未交付功能、未收集数据、未做课堂实证或未获授权的部署动作，统一标为“规划中”“待人工验证”或“待授权”。
- 最终演示、教师复核、真人浏览器/移动端/扫码、真实截图提供与权利确认均保留为人工事项。
