# Lumi 与方向二评分标准对齐备忘

## 已覆盖

| 评分项 | 当前证据 |
| --- | --- |
| 创新性与场景适配 | 设计说明定义视觉传达设计专业 11 门课程，优先课以数字交互文创与版式设计演示。 |
| 技术与数据合规 | 带来源课程语料、成长档案、证据式排错、匿名化和模型失败降级已写入设计与 runbook。 |
| 教学应用 | 结构化会诊、举一反三动作、轻教师台和验证模板形成“学—评—教”闭环。 |
| 用户体验与展示 | 10 分钟脚本含主线、切课、洞察台及降级路径。 |

## 缺口（待主线交付或材料投放）

- 配置台、洞察台、依赖度聚合与一致率工具的真实运行证据。
- 可回溯的 10–20 份匿名作业、教师标注及一致率/稳定性结果。
- 公开 HTTPS 链接、二维码、演示账号和最终截图。
- 技术架构图、部署说明和课程材料的可追溯来源。

## 建议调整项（待用户决策，不修改 spec）

1. 是否在视频开头先给出“解决什么教学问题”的 20 秒证据，再进入功能演示，以强化创新性与场景适配。
2. 是否将洞察台与验证结果安排为最后 2 分钟的固定展示，确保教学应用和实际效果不被前段功能淹没。
3. 是否在报告中把“推广价值”限定为“更换课程语料与导师配置可适配设计类课程”，避免夸大为已验证的跨专业/跨校规模化效果。
4. 是否在提交前补录一次模型失效降级演练，作为系统稳定性的可展示证据。
